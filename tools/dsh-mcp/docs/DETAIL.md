# Timing UI design MCP tools

Two local stdio MCP servers used while redesigning the Timing Android app:

- `uiux` → `ui-ux-pro-mcp` (design styles, colors, typography, Compose/Android guidelines)
- `wash` → `@menzies-mariesta-com/wash-compose-mcp` (Compose shell primitives, pigments, icons)

Both are installed globally with npm and launched by absolute path.
