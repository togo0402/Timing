# 变更记录

## 1.3.0（2026-11-27）

- 新增「记录导入 / 导出」：设置 → 数据。
- 导出可选时间范围（默认最近 7 天）与事件范围（分类树多选）；已结束记录按区间裁剪；JSON 文件/剪贴板。
- 导入支持文件/粘贴，按 path 补建分类，同 typeId+startAt+endAt 去重；报告导入/跳过/创建/非法。
- 新增域层单测 `RecordsImportExportTest`。

## 1.2.1

- 统计页支持切换其他日/周/月：左右导航 + 玻璃月历 + 回到今天。
- 计时页非今天时显示「今天」快捷胶囊。
- 分类批量选择后长按拖动移动：拖到分类=子级，拖到空白=一级；子树保持关系；禁止自身/子孙。

## 1.2.0

- 计时页改为横向 Gantt：0–24h 默认，双指缩放 30min–24h，单指横拖，纵向滚动。
- 日期胶囊 + 6×7 月历弹层。
- NFC/分类批量删除；NFC 单删确认。
- 全页面 Fluid Glass（统计/分类/NFC/导入导出/权限）。

## 1.1.4

- NFC 标签诊断（可写/只读/无 NDEF）。

## 1.1.3
